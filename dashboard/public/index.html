Pool state — three strictly separate value classes

Actual vault liquidity (idle)
–
Immediately withdrawable USDC held by the vault. This is the only value that is liquid today.
Outstanding principal (receivable)
–
Unserviced principal of live advances. A claim on future revenue — not liquidity, and not withdrawable by lenders.
Conditional lien targets
–
1.5× shortfall on defaulted advances. Recoverable only if the agent earns again through the registered route.

These three numbers are deliberately never added together into a single “assets” figure, and no lender return is implied.
